# Portfolio Data & IA

Portfolio premium de N'tcho Phanuel Eliel Koné, orienté Data Analyst / Data Scientist.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui-style primitives

## Commandes

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run build
```

## Déploiement

Le projet est prêt pour Vercel.

- Framework: Next.js
- Build command: `npm.cmd run build`
- Output: géré automatiquement par Next.js
